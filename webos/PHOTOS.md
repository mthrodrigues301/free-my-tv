# Personal photos

The Photos tab shows a horizontal carousel. Left/Right selects a photo; OK opens it full screen. Left/Right changes photos in full screen, and Back or OK returns to the carousel. Pointer controls are available too. Photos retain their proportions.

Personalized builds include `local-photos/NNN.jpg` and `NNN-thumb.jpg` pairs, ordered by filename. This directory is ignored by Git. Generic packages always contain an empty photo list. Never upload the personalized package to a public release: it contains the selected private photos.

The current local collection contains 23 photos converted from Downloads/fotos. Source files are unchanged. Refreshing the folder requires rebuilding the package; the TV does not read the notebook's Downloads directory over the network.
